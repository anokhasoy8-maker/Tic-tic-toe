# Tic-Tac-Toe

A small browser-based Tic-Tac-Toe game with:

- 2-player mode
- vs Computer mode
- score tracking
- restart and undo controls
- light/dark/neon themes
- sound effects

## Run locally

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages

This repository is ready to be served as a static site via GitHub Pages from the root folder.
